# lukasziegler.com

Personal site of Lukas Ziegler — static [Astro 5](https://astro.build) site, bilingual (EN/DE).

```sh
npm install
npm run dev      # localhost:4321
npm run build    # dist/
```

Conventions and structure: see [CLAUDE.md](CLAUDE.md).
Old setups: `hugo` branch (Hugo + Avenco theme) · `master` (legacy static site).
